# Semantic Versioning for Easy Login

The files contained in this directory have been taken from the [adamreeve/semver.net](https://github.com/adamreeve/semver.net/tree/master) GitHub repository, and have only been modified to the extend of preventing import issues with other packages that arise from shipping the original DLL and potentially also from shipping this source code unmodified.

The changes are as follows:
- Changed the namespace from `SemanticVersioning` to `Foxscore.EasyLogin.SemanticVersioning`
